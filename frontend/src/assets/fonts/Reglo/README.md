# Reglo Bold

Copyright (c) 2015 Sebastien Sanfilippo (www.love-letters.be).

Reglo Bold is a geometric sans designed by Sebastien Sanfilippo, initially for the identity of Radio Panik with Open Source Publishing.

- Source: https://github.com/sebsan/Reglo
- Upstream commit: `3b465388f0b45930e5217edc1fc82c5b6514e80c`
- License: SIL Open Font License 1.1 (`OFL.txt` in this directory)

`Reglo-Bold.otf` is the unmodified original. `Reglo-Bold.woff2` is the same font converted to WOFF2 for web embedding. Outlines were not edited, and the family name was not changed.
